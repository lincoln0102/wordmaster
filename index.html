四、辅导者速查口诀卡（零语法术语版）

暗号 1：看到“数量多”，名词变尾巴

  • 线索词：many（许多）、some（一些）、these（这些）。
  • 口诀：后面名词直接加 s；遇到 f 结尾（如 leaf），把 f 变成 ves（leaves）。
  • 特例第 8 题：work 变人加 er，前面有 are 表示多人，所以是 workers。

暗号 2：三种“动词胶水”

  • 原形胶水：看到 Let's，后面直接抄原词（take）。
  • to 胶水：看到 want / It's nice / excited，后面加 to + 原词。
  • 自由胶水：看到 like，加 to 或加 ing 都可以。

暗号 3：时间信号词

  • 看到句首 Look!（看！），表示正在发生 → am/is/are + 动词ing（are collecting）。
  • 看到 see + 事物（看见鸟正在飞） → 动词加 ing（flying）。
  • 没有 Look! 且主语是复数（animals） → 直接抄原词（collect）。

暗号 4：感叹句与句型变身术

  • 句首 How 感叹句：后面接形容词（beautiful、lovely）。
  • 修饰事物用 -ing（amazing 令人惊叹的桥）；修饰人用 -ed。
  • 改疑问句：有 is/are 把它提前；没 is/are 且动词有 s，请照妖镜 Does 放最前，动词变原形。
  • 改否定句：有 are 变 aren't（同时 some 变 any）；动词有 es，前面加 doesn't 并去掉 es。
